# Rule: no initialisms

An initialism is a name built from the first letters of words, read letter by
letter, like F B I.

## The demand (word for word)

> You will not use any initialisms

## The one exception: a proper name that is spelled that way

Some organizations, products, and standards have a first-letter string as their
actual registered name. Writing it out changes the name and can break a source
citation, so keep the name as it is spelled and say what it is on first use.

- Keep: "NASA Science", "BBC News", "IBM". These are names.
- Do not keep: "CDN", "HTTP", "RAM", "ASAP". These stand in for ordinary words and
  must be spelled out.
- On first use of a kept name, say what it is: "NASA, the United States space
  agency".

This exception covers names only. It is not a licence to keep any initialism that
happens to appear in a source. The same exception applies to stage 02.

## Good looks like

Context: explaining where a file is stored.

The document is kept on a network of servers that hold copies close to users. Your
computer downloads it over the normal web connection and keeps a copy in its fast
temporary memory.

## Bad looks like

Context: explaining where a file is stored.

The PDF is on the CDN; fetch it over HTTP and cache it in RAM.

## Why the bad one fails

- "PDF", "CDN", "HTTP", and "RAM" are first-letter names the reader must already
  know. Spell out the thing each one stands for.
