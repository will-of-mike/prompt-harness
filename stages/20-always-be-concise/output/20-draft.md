Storing passwords in plain text is dangerous. If anyone reads the database, every
password is exposed at once. Scramble each password into a form that cannot be read
back, and never store the raw text. Source: Password Storage Cheat Sheet, OWASP
Cheat Sheet Series. Link:
https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html
